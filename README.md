# Projetos web

Apresentação de sete projetos, com seus objetivos e tecnologias identificadas nos respectivos arquivos de desenvolvimento.

| Projeto | Apresentação | Tecnologias |
|---|---|---|
| **Topa** | Aplicativo de desafios, com interface web e servidor próprio. | React, Vite, TypeScript e MySQL |
| **Saúde Mental Aprova** | Aplicação voltada à saúde mental, com cadastro, autenticação e áreas de acesso para diferentes perfis. | Next.js, React, TypeScript e PostgreSQL |
| **Clínicas SaaS** | Piloto de uma plataforma para clínicas, com autenticação e estrutura para diferentes organizações. | Next.js, React, TypeScript e PostgreSQL |
| **Cria Club RJ** | Aplicação web com organização de páginas localizadas. | Next.js, React, TypeScript e PostgreSQL/Supabase |
| **Gerador de Landing Pages** | Ferramenta de criação de páginas para salões, com áreas de administração e edição. | Next.js, React, TypeScript e Supabase |
| **Galeria SaaS** | Aplicação para galerias de imagens. | Next.js, React, TypeScript e Supabase |
| **CRM — BET — Tratamento (IPJ)** | Sistema CRM com autenticação e áreas de acesso. | Next.js, React, TypeScript e PostgreSQL |

## Organização técnica

Os projetos usam React e TypeScript nas interfaces. Topa utiliza Vite; os demais têm Next.js entre suas dependências. MySQL e PostgreSQL atendem às camadas de dados identificadas, e alguns projetos utilizam Supabase.

Esta apresentação é mantida em um repositório independente. Os repositórios de implementação são privados. As descrições apresentam o escopo observado no código e na documentação; não representam métricas de uso ou garantias de operação em produção.
